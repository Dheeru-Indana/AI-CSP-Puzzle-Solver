# 🧠 AI Constraint Puzzle Solver

An interactive web application that demonstrates **Artificial Intelligence problem-solving using Constraint Satisfaction Problems (CSP)**.

This platform allows users to **play, visualize, and understand how AI solves complex puzzles step-by-step** using algorithms like backtracking and constraint propagation.

---

## 🚀 Features

### 🎮 Game Modes

* 🔢 **Crypt Arithmetic Solver**

  * Solve puzzles like `SEND + MORE = MONEY`
  * Assign digits to letters with constraints

* 🎨 **Map Coloring**

  * Color regions such that no adjacent regions share the same color
  * Visual representation of graph-based CSP

* ⚙️ **Custom CSP Builder**

  * Define your own variables, domains, and constraints
  * Run AI to solve custom problems

---

### 🤖 AI Capabilities

* Backtracking algorithm
* Constraint checking
* Step-by-step solving visualization
* Real-time variable assignment tracking

---

### 📊 Visualization & Insights

* AI decision logs
* Backtracking steps
* Performance metrics:

  * Nodes explored
  * Time taken
  * Number of backtracks
