# 🧠 AI Constraint Puzzle Solver

An advanced, interactive web application that demonstrates **Artificial Intelligence problem-solving using Constraint Satisfaction Problems (CSP)** with a **modern, cinematic UI and real-time visualization engine**.

This platform allows users to **play, explore, and deeply understand how AI solves complex problems**, combining powerful algorithms with **high-performance execution and Apple-inspired design aesthetics**.

---

## 🚀 Features

### 🎮 Game Modes

* 🔢 **Crypt Arithmetic Solver**

  * Solve puzzles like `SEND + MORE = MONEY`
  * Assign digits with strict constraints and validation

* 🎨 **Map Coloring**

  * Color regions ensuring no adjacent regions share the same color
  * Graph-based constraint visualization

* ⚙️ **Custom CSP Builder**

  * Define variables, domains, and constraints
  * Execute AI solver on custom problems

---

## 🤖 Advanced AI Engine

* Optimized **Backtracking Algorithm**
